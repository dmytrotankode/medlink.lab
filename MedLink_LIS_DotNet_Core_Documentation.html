2. Багатошарове каскадне нашарування норм Delphi (C# Engine)

У спадковій Delphi-системі норма ніколи не була статичною. Для кожної конкретної методики (напр. HEX_IFCC) діє багатошаровий каскад правил, де шар із вищим пріоритетом перекриває нижчі:

Пріоритет Архітектурний шар Критерії активації Приклад клінічної дії
P = 100 ШАР 3: PREGNANCY (Вагітність) Пацієнт жіночої статі, вказано термін вагітності в тижнях Триместр 2 (14-27 тиж.): коридор [3.5 — 5.3] ммоль/л перекриває звичайні норми
P = 80 ШАР 2: MENSTRUAL_PHASE (Менструальний цикл) Жінки, вказано фазу (Фолікулярна, Овуляторна, Лютеїнова, Менопауза) Лютеїнова фаза коригує норму прогестерону чи глюкози
P = 60 ШАР 4: CLINICAL_ICD10 (Клініко-нозологічний) Встановлено клінічний діагноз МКХ-10 (напр. E11, N18) Таргетний терапевтичний коридор компенсації цукрового діабету
P = 40 ШАР 1: DEMOGRAPHIC (Вік та стать) Стратифікація: Немовлята (0-28 днів), діти (1-14 р.), дорослі, літні (65+) Вік нормалізується у дні для точного відсікання немовлят від дорослих
P = 10 ШАР 0: BASELINE (Базовий оптимум методики) Завжди активний як універсальний запасний fallback Стандартний референтний інтервал аналізатора за замовчуванням

Реалізація у C# сервісі (LabNormsCascadeService.cs):

// Нормалізація віку пацієнта до днів для медично точного порівняння:
double ToDays(double val, string unit) => (unit?.ToUpperInvariant()) switch
{
    "DAYS" => val,
    "MONTHS" => val * 30.4375,
    _ => val * 365.25
};

double pDays = ToDays(req.Age, req.AgeUnit);
double lFromDays = ToDays(layer.AgeFrom, layer.AgeUnit);
double lToDays = ToDays(layer.AgeTo, layer.AgeUnit);

if (pDays < lFromDays || pDays > lToDays)
{
    match = false;
    reason = $"Вік {req.Age} {req.AgeUnit} поза межами діапазону [{layer.AgeFrom}-{layer.AgeTo} {layer.AgeUnit}]";
}

3. Перевірка працездатності через PowerShell / cURL

Усі команди виконуються проти робочого .NET сервісу на порту 5055:

1. Перевірка Swagger UI:

curl.exe -s http://localhost:5055/swagger/index.html | Select-String "<title>"
# Відповідь: <title>Swagger UI</title>

2. Завантаження 49 шарів правил із бази даних SQLite:

(Invoke-RestMethod -Uri "http://localhost:5055/api/laboratory/norms/combinations").data.Count
# Відповідь: 49

3. Запуск каскадного резолвінгу для вагітної пацієнтки 2-го триместру:

$body = @{
    testCode = "GLU"
    methodCode = "HEX_IFCC"
    gender = "F"
    age = 28
    isPregnant = $true
    pregnancyWeek = 20
    measuredValue = 5.2
    previousValue = 4.8
} | ConvertTo-Json

$res = Invoke-RestMethod -Uri "http://localhost:5055/api/laboratory/norms/resolve-cascade" -Method Post -Body $body -ContentType "application/json"
$res.winningLayer.normName
# Відповідь: Вагітні: 2-й триместр (14-27 тиж.)

4. Перевірка роздачі веб-інтерфейсу сервером Kestrel:

curl.exe -I http://localhost:5055/medlink_lab_frontend/run_prototype.html
# Відповідь: HTTP/1.1 200 OK (Content-Length: 282777, Server: Kestrel)
