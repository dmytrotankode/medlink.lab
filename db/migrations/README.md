# Міграції схеми для перенесення в MedLink (evomis)

ЛІС працює автономно на SQLite. Схема створюється з EF-моделі (`EnsureCreated`), а для наявних баз її дооновлює `SchemaUpgrader` при запуску. Для перенесення в MedLink (PostgreSQL) кожна зміна схеми після v4.0 фіксується ідемпотентним SQL-скриптом у цій теці.

Позначки в коментарях скриптів:
- **[MedLink]** — сутність evomis, структура не змінюється;
- **[MedLink+]** — сутність evomis, до якої модуль додає колонки;
- **[ЛІС]** — таблиця модуля «Лабораторія»;
- **[MedLink-new]** — нова загальна сутність МІС, пропонується до ядра MedLink.

| Скрипт | Задача | Розділ ТЗ |
|---|---|---|
| `R1.1/001_fr_pre_004_tube_rules.sql` | FR-PRE-004 правила окремих/об'єднаних пробірок | 20.1 |
| `R1.1/002_send_out_external_labs.sql` | Зовнішні лабораторії (send-out): виконавці, прайс, реєстри, вкладення | 20.3 |
| `R1.1/003_fr_ref_001_referrals.sql` | FR-REF-001 типи направлень, паперові направлення, журнал обміну з ЕСОЗ | 20.6 |
| `R1.1/005_fr_ref_002_clients_and_revision.sql` | FR-REF-002 клініки-клієнти, ревізія 20.9 (без змін схеми) | 20.8–20.9 |
| `R1.1/004_fr_gap_060_billing.sql` | FR-GAP-060 оплата: прайси, пакети, платники, поліси ([MedLink-new]), нарахування, каса, рахунки | 20.7 |
| `R1.1/006_ch21_23_mis_routing_distribution_ehealth_sign.sql` | Інтервенції ЕСОЗ, послуги обладнання, маршрутизація, направлення МІС і пакети, розподіл, сесія/підпис/відправка ЕСОЗ, агрегати звітів | 21, 23 |
| `R1.1/007_ch22_pathology.sql` | Патоморфологія: направлення ПГД (014/о), об'єкти, блоки, скельця, етапи, висновок з версіями, ІГХ, CITO, архів; довідники (шаблони, МКХ-О, методики, reflex ІГХ, типи матеріалу, фіксатори, причини відмови) | 22 |
| `R1.1/008_biochem_catalog_reference_dictionaries.sql` | Одиниці виміру та перерахунок, вікові групи, причини браку/відмови, журнал стартових наборів; колонки unit_id/age_group_id/source у нормах, unit_id у показниках, коди причин у пробірках і замовленнях | Біохімічний каталог |

Повна схема модуля для PostgreSQL генерується з EF-моделі: `db/postgres/medlink_lis_schema.sql` (див. `db/postgres/README.md`). Скрипти в цій теці — інкрементні зміни для вже розгорнутої схеми.
