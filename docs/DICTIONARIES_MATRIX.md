## 5. Біохімічна лабораторія: чи повні довідники

Стенд: 32 показники категорії BIOCHEM, 6 коагуляції, 10 сечі, 17 гематології, 14 імуно.

Є: основні ферменти (АЛТ, АСТ, ЛФ, ГГТ, амілаза), субстрати (глюкоза, креатинін, сечовина, сечова кислота, білірубін заг./прямий, загальний білок, альбумін), ліпіди (ХС, ТГ, ЛПВЩ, ЛПНЩ), електроліти (K, Na, Cl, Ca, іонізований Ca), залізо, СРБ, лактат, HbA1c, КЛС (pH, pCO2, pO2, BE, HCO3, SO2). Норми: для більшості 2–4 шари (дорослі/за статтю/базовий), глюкоза — 13 шарів (вагітність, цикл, діти, МКХ).

Прогалини:
1. Методики: у жодного з 82 показників не заповнено `methodId` (методики є лише текстом у шарах норм) — методики в картці показника порожні.
2. Відсутні поширені показники: магній, фосфор неорганічний, ЛДГ, КК та КК-МВ, непрямий білірубін (розраховується), холестерин не-ЛПВЩ/індекс атерогенності (розрахункові), трансферин/ЗЗЗС, феритин є в імуно, але немає альбумін/креатинін у сечі, сечовий білок добовий, амілаза панкреатична, лужна/кисла фосфатаза, холінестераза, ревмофактор, АСЛО, мікроальбумін, цистатин C, інсулін/C-пептид, HOMA, електрофорез білків, швидкість клубочкової фільтрації (розрахунок за креатиніном).
3. Для 23 з 82 показників немає LOINC (серед біохімії: прямий білірубін, КЛС, іонізований Ca).
4. Дитячі норми відсутні для більшості показників (лише дорослі 16–120 р. у частини; немає норм для новонароджених/дітей за віковими групами: ALP, креатинін, білірубін новонароджених).
5. Для BIL_DIR, ICA, BE, HCO3, PCO2, PH, PO2, SO2 — єдиний базовий шар без статі/віку (для КЛС прийнятно).
6. Єдиний тип пробірки для біохімії — гелева сироватка (SERUM_GEL); немає пробірки з фторидом (глюкоза/лактат), тимчасової пробірки для сечі добової, червоної без гелю. Біоматеріали названі кодами BM_01…BM_18.
7. Одиниці — вільний текст, без перерахунку SI ↔ традиційні (ммоль/л ↔ мг/дл).

Висновок: для демонстрації та пілоту на 30 основних біохімічних показниках достатньо; для реального запуску біохімічної лабораторії — ні (див. P0/P1).

## 7. Примітки до доступу та перевірки
- Ролі: екран «Довідники» Admin/Doctor/Technician; запис — Admin, Doctor; видалення — Admin. Розбіжність: Technician бачить екран, але створити/змінити запис не може (потрібно виокремити режим «лише перегляд» у UI або дати право).
- На стенді перевірено: екран «Довідники» відкривається (13 карток), усі 12 довідників універсального CRUD повертають дані, `/norms/combinations` (175 шарів), `/price-lists`, `/payers`, `/performers`, `/sections`, `/logistics/container-types`, `/qc/materials`, `/reagents/lots`, `/biobank/racks`, `/pathology/rooms`, `/settings/numerators` повертають 200. Запису на стенді не робилося.
