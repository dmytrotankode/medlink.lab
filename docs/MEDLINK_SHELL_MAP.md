# Умовна оболонка МедЛінк: що в нашому SPA належить МІС

Фронту МІС МедЛінк для розробки немає. Щоб команда МедЛінк бачила межу, SPA лабораторії показує **умовну оболонку** (верхня смуга) і ненав'язливі значки «Ця частина належить МедЛінк — вбудувати у реальний фронт». Це орієнтир, а не продукт: у реальній системі ці елементи надає МІС, а екрани лабораторії (`/laboratory/*`) вбудовуються під її шапкою.

## Керування
| Спосіб | Дія |
|---|---|
| Змінна середовища `LIS_SHELL_HINTS=0` | вимикає і оболонку, і значки (пріоритетніша за конфіг) |
| Конфіг `Lab:ShellHints=false` | те саме, якщо змінної немає |
| `GET /api/v1/lab/auth/config` → `shellHints` | прапорець для SPA (без секретів, доступний без входу); за замовчуванням `true` |
| Перемикач «Підписи вбудовування» у смузі оболонки | особисте приховування значків (зберігається в браузері, ключ `medlink.lis.shellHints`) |

Режими `None`/`Header`/`Oidc` не змінено: оболонка лише читає `auth/config` і токен, нічого не надсилає.

## Таблиця: елемент оболонки → що надає МІС → контракт
| Елемент (де в SPA) | Що надає МІС | Контракт (токен, API, події) |
|---|---|---|
| Верхня смуга, логотип «МедЛінк» (`components/medlink-shell/MedlinkShell.vue`) | Шапка й брендинг фронту МедЛінк | Немає: чиста розмітка; лабораторія не залежить від шапки |
| Головне меню МІС: Пацієнти, Декларації, Прийоми… (заглушки) | Головне меню фронту | Немає. Заглушки лише показують місце плитки |
| Плитка «Лабораторія» | Пункт меню/плитка модуля, перехід у ту саму вкладку | Посилання на `{PathBase}/` (типово `/lab/`), SSO через Identity: клієнт `MisFront`/`LabFront`, redirect `{PathBase}/callback` (див. `MEDLINK_INTEGRATION_PLAN.md`, п. 4б, 4г) |
| Блок користувача й профілю (ім'я, посада/роль, лабораторія) | Вибір профілю й організації, поточний користувач | Oidc: ім'я з токена (`name`/`preferred_username`), особа = `sub` → `org_employee.id`; роль — `GET /api/v1/lab/context/me` (`labRole`, мапінг профілів МІС у `Medlink:ProfileRoles`). None/Header: співробітник із «Працюю як…» (`X-MedLink-Employee-Id`) |
| Кнопка «Вийти» | Завершення сесії | Oidc: `signoutRedirect` на Identity, повернення на `postLogoutPath`. Без входу — лише повідомлення |
| Шапка модуля: значок «Вхід і профіль — Identity МедЛінк» (`BaseLayout.vue`) | Вхід, оновлення токена | Authorization Code + PKCE, scope з `auth/config`; `Authorization: Bearer` на кожен запит; 401 → повторний вхід |
| Значок біля бічного меню (`menuDrawer.vue`) | Секція «Лабораторія» в бічному меню МІС | Пункти й маршрути `/laboratory/*`; видимість за роллю — `utils/menuAccess.js` (ключ — `labRole` з `context/me`) |
| Вибір пацієнта (`PatientSelect.vue`) | Пошук і картка пацієнта | Лабораторія приймає `patientId` (id картки МІС); пошук — `IMisDirectory.SearchPatientsAsync` (лише читання); створення/редагування карток — тільки в МІС (409 у режимі моста) |
| Чип ЄСОЗ і підпис КЕП (`EhealthSessionChip.vue`) | Сесія ЄСОЗ, підпис КЕП, eHealth-проксі | `docs/EHEALTH_MEDLINK_PROXY_CONTRACT.md`: токен ЄСОЗ зберігає проксі, ЛІС його не бачить; підтвердження звіту — КЕП |
| Друк бланків (`HtmlPreviewDialog.vue`) | Сервіс друку й підпису офіційних форм | Лабораторія віддає HTML/PDF бланка за URL API (`openAuthorized` додає токен); друк/КЕП — на боці МІС |
| Події результатів (немає елемента UI) | Прийом результату у висновок МІС | Канал B з `MEDLINK_INTEGRATION_PLAN.md`, п. 5 (`LabResultsController`, `X-Api-Key`); до появи — подія `MisReferralService.EmitFor` |

## Як вбудовувати
1. Взяти екрани з `src/MedLink.LIS.Web/src/pages/laboratory/*` і `layouts/baseLayout` як мікрофронт за `/lab/` (iframe або окремий SPA під тим самим доменом; токен спільний через Identity).
2. Шапку, головне меню, перемикач профілів, вихід — прибрати з нашого коду, залишивши лише рядок швидких індикаторів лабораторії.
3. Вимкнути оболонку й значки: `LIS_SHELL_HINTS=0`.
