# Документація MedLink LIS 4.0 — покажчик

## Як вносити зміни

1. Зміни маршрутів, DTO, статусів — спочатку в `API_CONTRACT.md`, потім відповідні правки у ТЗ v4.
2. Нова або змінена задача власника — у `РЕЄСТР_ЗАДАЧ.md` та розд. 2 ТЗ v4 одночасно (ідентифікатор `T-nnn` не перевикористовується).
3. Нова функціональна вимога — додати `FR-<модуль>-<nnn>` у розд. 4 ТЗ та рядок у матрицю трасування (Додаток E).
4. Матеріали в `docs/analysis/` не редагуються; за потреби додається новий файл із датою.
