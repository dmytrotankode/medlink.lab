💡 Клінічно-технічне роз'яснення процесу: Пункт забору біоматеріалу (Phlebotomy Station)
Стандарти: CLSI H3-A6, ISO 6710, ISO 15189

Призначення та мета процесу: Забезпечення безпомилкової ідентифікації пацієнта, перевірка преаналітичних вимог, авторозподіл тестів за пробірками та формування машинозчитуваного маркування.

Покроковий регламент виконання:
  1. Ідентифікація пацієнта за двома критеріями (ПІБ + дата народження) та підтягування е-направлення з ЕСОЗ eHealth.
  2. Заповнення обов'язкового чек-листа готовності (стан натщесерце, прийом медикаментів).
  3. Візуальний контроль послідовності взяття крові за CLSI H3-A6 Order of Draw (Цитрат -> Сироватка -> ЕДТА).
  4. Миттєвий мережевий друк етикеток зі штрихкодами Code128 на термопринтери Zebra без відкриття вікон діалогів.
