Стандарти: GDP Pharma, ISO 15189 п. 5.4.6, Наказ МОЗ №1051

Призначення та мета процесу: Гарантія збереження цілісності зразків під час транспортування між філіями та центральною лабораторією, контроль температурних режимів та вхідна вибраковка неякісних біоматеріалів.

Покроковий регламент виконання:
  1. Формування електронного маніфесту в пункті забору та пакування пробірок у термоконтейнер.
  2. Валідація показників термодатчика при прибутті кур'єра (діапазон +2...+8°C, без заморожування чи перегріву).
  3. Швидкісне штрихкод-сканування на сортувальному столі (Accessioning Desk) для підтвердження отримання.
  4. У разі виявлення гемолізу, хілозу чи згустків — миттєве оформлення акта бракеражу з автопризначенням перезабору.
