# Повторний прохід G4 (стенд /lab/), 09.11.2026

Стенд: https://med-one.avowiz.com/lab/ (Claude in Chrome, власна вкладка). Код не змінювався. Дані тестові (dev); у прайсі правка не зберігалась (вихід через діалог «Вийти без збереження»), оплата не проводилась.

## Важливе зауваження щодо методики

- ID ролей із завдання (`00000000-0000-0000-0000-00000000000N`) на стенді не діють: застосунок мовчки підставляє «Бондар Н. І., медсестра» (ознака: заголовок, меню з 7 пунктів). Справжні ID мають вигляд `0e000000-0000-0000-0000-00000000000N` (видно в «Налаштування лабораторії»). Тому ролі перемикались через список «Працюю як…» у шапці; роль у кожному прогоні перевірялась за ПІБ у шапці.
- Інші агенти перезаписують `localStorage` — тому прямі URL перевірялись через `router.push` у вкладці з уже обраною роллю (без перезавантаження).
- Інтерактивні інструкції прогонялись реальним плеєром (кнопки «Далі →» / «Зроби за мене» / «Пропустити крок →»); 118 сценаріїв першим проходом, 45 сценаріїв (найпроблемніших) — другим, з очікуванням 15 с на крок. Додатково статично перевірено всі 1414 кроків із 266 сценаріїв: чи знаходиться якір на сторінці кроку.
- НЕ перевірялось: мережеві 4xx/5xx (інструмент мережі не підключався), вузька ширина вікна, озвучення голосом «Остап» (Edge), Журнал направлень МІС (на стенді порожній — «Направлень МІС немає»), реальний вхід в ЄСОЗ.
