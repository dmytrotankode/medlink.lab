## Обмеження проходу (чесно)
- Вбудована панель браузера була прихована: скріншоти і геометрія елементів недоступні (розміри/перекриття не перевірялись), випадні списки не промальовувались. Перевіряв тексти й структуру через DOM, мережу — через Resource Timing та журнал запитів. Ширина вікна 1024x768.
- Ключ ролі спільний із іншими агентами (в панелі працювали ще вкладки); перед кожною перевіркою роль звірялась по шапці. Один раз набір тексту через інструмент потрапив у чужу вкладку (tab-4), у моїй нічого не змінилось.
- Помилки консолі/мережі: 4xx/5xx на екранах зони не виявлено (6 штук 404 — мої власні пробні запити до неіснуючого шляху, артефакт). Є `ERR_BLOCKED_BY_CLIENT` для запитів до локального агента друку (localhost:5088) і періодично для окремих запитів сторінки — обмеження панелі, не стенда; один раз через це «Вхідні направлення» показали «API лабораторії недоступне».
