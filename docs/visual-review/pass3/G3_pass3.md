## Умови прогону (важливо)
- Роль: адміністратор `0e000000-0000-0000-0000-000000000001` («Мельник Вікторія Степанівна, Адміністратор лабораторії»), звірено за шапкою. Один раз за час прогону `localStorage.medlink.lis.employeeId` змінив інший агент на `...004` (спільний профіль браузера): шапка лишилась «адміністратор», а API повернув 403, тому далі всі виклики йшли з явним заголовком `...001`.
- Помилки `net::ERR_BLOCKED_BY_CLIENT` / «Failed to fetch» і банер «API лабораторії недоступне» під час прогону НЕ є дефектами стенда: це блокування запитів середовищем браузерної панелі (панель була прихована, «policy check unavailable»). Дефектів за цим не заводити.
- Консоль/мережа: власних 4xx/5xx застосунку не виявлено; усі 403/404/400 у журналі походять від моїх цілеспрямованих перевірок (роль без прав, неіснуючі шляхи `notifications/patient`, `mis-events`, `health`, порожні тіла).
