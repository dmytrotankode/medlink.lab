# MedLink LIS — автономний екземпляр для аналітика

## Встановлення
1. Запустіть `MedLink_LIS_Setup_v4.1.0.exe` (потрібні права адміністратора). .NET встановлювати не потрібно — сервер self-contained.
2. За бажанням позначте «Одразу встановити коннектор аналізаторів» (потрібен лише на ПК біля приладів).
3. Після встановлення відкриється браузер з ЛІС: `http://localhost:5055`.

## Запуск і зупинка
- **Пуск → MedLink LIS → MedLink LIS** (або ярлик на робочому столі): запускає сервер у фоні та відкриває браузер. Перший запуск створює демо-базу (до 1–2 хв).
- **Зупинити MedLink LIS** — зупиняє сервер.
- **Скинути демо-базу** — поточна база зберігається в резервну копію, наступний запуск створить чисті демо-дані.

Дані: `%LOCALAPPDATA%\MedLink LIS\data\medlink_lis.db`, журнали сервера: `%LOCALAPPDATA%\MedLink LIS\logs`.

## Що налаштовано в автономному режимі
- **Без авторизації**: користувач обирається перемикачем «Працюю як…» у правому верхньому куті (ролі: адміністратор, лікар-лаборант, лаборант, медсестра пункту забору, кур'єр, реєстратор).
- **ЕСОЗ (eHealth) — мок**: усі дії з е-направленнями виконуються реальними викликами API ЕСОЗ, на які відповідає вбудований мок. Журнал обміну: `GET /api/v1/lab/ehealth/exchange-log`.
- **Демо-дані**: пацієнти, замовлення в різних статусах, аналізатори, ВКЯ, лабораторії-партнери (Сінево, TerraLab), платники (каса, страхові УНІКА й ІНГО, НСЗУ, клініка «Здоров'я»), поліси, е-направлення (№ `0001-2026-A7K3` — за програмою НСЗУ).

## Що перевірити (сценарії ТЗ, розд. 20)
| Сценарій | Де |
|---|---|
| План пробірок (окрема тара, об'єм, порядок забору) | Реєстрація направлень → «Нове направлення» |
| Е-направлення: пошук, взяти в роботу, погашення при видачі | «Нове направлення» → тип «Е-направлення», номер `0001-2026-A7K3` |
| Оплата: каса, страхова (90 % / франшиза), НСЗУ + платні позиції | «Нове направлення» → «Платник»; картка замовлення → блок «Оплата» |
| Зовнішні лабораторії (Сінево): черга, реєстр, результати, PDF | Меню «Зовнішні лабораторії» |
| Клініки-клієнти: реєстр CSV, акт за період | Меню «Клієнти (клініки)» |
| Журнал направлень, прайси та платники | Меню «Журнал направлень», «Прайси та платники» |
| Пункт забору, робочий стіл, валідація, ВКЯ, біобанк, мікробіологія, TAT | Відповідні пункти меню |

## Документація
Пуск → MedLink LIS → **Технічне завдання (ТЗ)** / **Документація** (ТЗ HTML і Markdown, контракт API, swagger.json, скріншоти, міграції PostgreSQL для перенесення в MedLink, відеоогляд).

## Коннектор аналізаторів
Пуск → MedLink LIS → **Встановити коннектор аналізаторів**. У ЛІС: «Аналізатори та коннектори» → «Додати коннектор» → ключ інсталяції → вказати в майстрі коннектора разом з адресою сервера `http://<IP ПК з ЛІС>:5055`. Детально — `docs` та README коннектора.
